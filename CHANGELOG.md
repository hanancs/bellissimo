# Change Log

All notable changes to the "bellissimo" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.2] - 2026-05-02

### Added
- New **Bellissimo Midnight** variant: A deep, high-contrast dark theme optimized for OLED displays.
- New **Bellissimo Light** variant: A clean and crisp light mode for daytime productivity.
- New **Bellissimo Icons** theme: Custom-designed file icons that match the Bellissimo aesthetic.
- Support for **Semantic Highlighting** across all theme variants.
- Professional `README.md` with detailed installation and features.

### Changed
- Improved extension metadata and keywords for better discoverability.
- Refined UI colors in the main Bellissimo theme (terminal, sidebar, etc.).
- Updated VS Code engine requirement to 1.60.0.
